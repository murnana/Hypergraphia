# デプロイメント

Hypergraphia のデプロイメントに関する手順・設定情報です。

## 📋 目次

### 開発環境
- **環境構築** - 開発環境のセットアップ手順
- **依存関係** - 必要なツール・ライブラリ
- **ローカル実行** - 開発環境での実行方法
- **デバッグ設定** - デバッグ環境の構成

### ビルド・パッケージング
- **ビルド設定** - プロジェクトのビルド構成
- **AOT コンパイル** - Ahead-of-Time コンパイルの設定
- **プラットフォーム固有設定** - 各プラットフォーム向けビルド
- **パッケージング** - 配布パッケージの作成

### CI/CD
- **GitHub Actions** - 継続的インテグレーション設定
- **自動テスト** - テスト自動化の設定
- **アーティファクト管理** - ビルド成果物の管理
- **リリース戦略** - リリースプロセス

### 本番環境
- **インフラ要件** - 本番環境のシステム要件
- **サーバー設定** - Web サーバー・アプリケーションサーバー設定
- **データベース設定** - 本番データベースの構成
- **監視・ログ** - 運用監視とログ管理

### クラウドデプロイメント
- **Azure** - Microsoft Azure へのデプロイ
- **AWS** - Amazon Web Services へのデプロイ
- **Docker** - コンテナ化とコンテナデプロイメント
