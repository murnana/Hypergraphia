# Hypergraphia ドキュメンテーション構造

このディレクトリには Hypergraphia プロジェクトの全ドキュメンテーションが含まれています。

## 📁 ディレクトリ構造

```
docs/
├── index.md                  # ドキュメンテーションポータル（メインページ）
├── README.md                 # このファイル（構造説明）
├── manuals/                  # ユーザーマニュアル
│   ├── index.md             # マニュアル一覧
│   ├── user-guide/          # エンドユーザー向けガイド
│   ├── admin-guide/         # 管理者向けガイド
│   └── api-reference/       # API リファレンス
├── development/              # 開発者向けドキュメント
│   ├── index.md            # 開発者ドキュメント一覧
│   ├── architecture/       # システムアーキテクチャ
│   ├── deployment/         # デプロイメント手順
│   └── contributing/       # コントリビューションガイド
└── assets/                   # ドキュメント用画像・リソース
```

## 🎯 ドキュメント分類

### 📚 マニュアル (`manuals/`)
**対象**: エンドユーザー・管理者・API利用者

- **user-guide/**: 一般ユーザー向けの操作マニュアル
- **admin-guide/**: システム管理者向けの運用・設定ガイド
- **api-reference/**: 開発者向けAPI仕様書

### 🛠️ 開発者向けドキュメント (`development/`)
**対象**: プロジェクト貢献者・開発者

- **architecture/**: システム設計・技術アーキテクチャ
- **deployment/**: 開発環境構築・デプロイメント手順
- **contributing/**: プロジェクトへの貢献方法・開発ガイドライン

1. **日本語での記述**: 全ドキュメントは日本語で記述
2. **構造化された情報**: 目次・セクション・リンクを活用
3. **実用性重視**: 具体的で実践的な情報を提供
4. **保守性**: 定期的な更新・メンテナンス
5. **アクセシビリティ**: 適切な見出し構造とナビゲーション
